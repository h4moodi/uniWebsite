# uniWebsite# hama-shazad.dev  CS304 Web Technologies Project

A personal study and revision tracker built as a university project for CS304 Web Technologies at the University of Kurdistan Hewler. Designed, written, and coded from scratch without any frameworks or libraries.

## What it is

A multi-section single-page website that documents my learning progress across web technologies, Linux, networking, and Ruby programming. Built to demonstrate mastery of core HTML and CSS concepts covered in the CS304 syllabus.

## What I built

- Sticky navigation bar with smooth scroll anchor links
- Hero section with animated background and custom typography
- CSS Grid and Flexbox layouts throughout
- Subject cards with structured content using definition lists
- Interactive study log with timestamped entries
- Contact form with fieldsets, labels, text inputs, email inputs, a select dropdown, radio buttons, checkboxes, and textarea
- Sidebar with a quick reference panel and an evidence summary table
- Fully semantic HTML: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `dl`, `fieldset`, `legend`, `time`

## Concepts covered

| Category | Details |
|---|---|
| Semantic HTML | header, nav, main, section, article, aside, footer, figure, time, dl, fieldset |
| CSS Selectors | element, class, id, pseudo-class (:hover, :focus), attribute, descendant, child |
| Box Model | width, height, padding, border, margin, box-sizing, overflow |
| Flexbox | flex-direction, justify-content, align-items, flex-wrap, gap, order |
| CSS Grid | grid-template-columns/rows/areas, fr, repeat(), gap, grid-column/row |
| Positioning | sticky header, relative, z-index |
| Typography | font-family, rem/em sizing, font-weight, line-height, Google Fonts |
| Forms | input (text, email, radio, checkbox), select, textarea, label, fieldset |

## Stack

Pure HTML and CSS. No JavaScript frameworks, no CSS frameworks, no build tools.

## How to run

Open `index.html` in any browser. No setup required.
